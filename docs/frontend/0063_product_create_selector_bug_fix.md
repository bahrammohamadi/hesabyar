# 0063 — رفع باگ ساخت کالا از داخل انتخابگر خرید

## گزارش کاربر
کاربر هنگام ثبت خرید، در انتخاب کالا، کالای «شومیز شانتون رنگی» را چند بار ایجاد کرده بود، اما در لیست کالاها/انتخابگر ظاهر نمی‌شد.

## علت دقیق
`ProductSelector` فقط `product_variants` را نمایش می‌دهد، نه خود رکورد `products` را.

در `ProductPanel` هنگام create، اگر کاربر فقط نام کالا را وارد می‌کرد و هیچ ردیف واریانتی را پر نمی‌کرد، فقط رکورد `products` ساخته می‌شد و هیچ `product_variants` ساخته نمی‌شد. بنابراین کالا در دیتابیس وجود داشت ولی در انتخابگر کالا دیده نمی‌شد.

## اصلاح کد
فایل:

```text
src/shared/panels/ProductPanel.tsx
```

تغییرات:

- اگر ProductPanel در حالت create با `initialName` از ProductSelector باز شود، نام کالا از جستجو prefill می‌شود.
- اگر هنگام ذخیره محصول هیچ واریانتی پر نشده باشد، یک واریانت پیش‌فرض «ساده» با قیمت‌های پایه ساخته می‌شود.
- بنابراین کالا بلافاصله در ProductSelector قابل انتخاب می‌شود.

## اصلاح داده موجود
در production مشخص شد سه رکورد محصول فعال با نام «شومیز شانتون رنگی» ساخته شده‌اند ولی هیچ واریانت فعالی ندارند:

```text
code 1490
code 1491
code 1492
```

برای هر سه رکورد یک واریانت ساده با stock_qty=0 ساخته شد تا در انتخابگر کالا دیده شوند. هیچ محصولی حذف یا غیرفعال نشد.

واریانت‌های ساخته‌شده:

```text
db775b38-c638-4dde-9049-79c2e1357151 → product 3cd50bfd... → sku 1490
0c0f8713-b032-4491-8a2d-2ed6f2b17049 → product 746ded1a... → sku 1491
cbc180c2-1c77-4975-b460-61499619e81f → product 05d7c750... → sku 1492
```

## نکته
چون کاربر چند بار تلاش کرده بود، سه محصول تکراری ایجاد شده‌اند. برای جلوگیری از حذف اشتباه، هیچ‌کدام حذف یا غیرفعال نشدند. کاربر می‌تواند بعداً نسخه‌های اضافه را خودش غیرفعال کند یا با تأیید صریح، فقط یکی را نگه داریم.

# 0064 — مرتب‌سازی بر اساس کد مشتری و کد کالا

## تغییرات

### لیست اشخاص

فایل:

```text
app/(app)/contacts/page.tsx
```

گزینه‌های مرتب‌سازی اضافه شد:

```text
کد صعودی
کد نزولی
```

مرتب‌سازی با `localeCompare(..., { numeric: true })` انجام می‌شود تا کدهای عددی طبیعی‌تر مرتب شوند.

پیش‌فرض لیست همچنان:

```text
جدیدترین
```

### لیست کالاها

فایل:

```text
app/(app)/products/page.tsx
```

گزینه‌های مرتب‌سازی اضافه شد:

```text
کد کالا صعودی
کد کالا نزولی
```

پیش‌فرض لیست کالا از قبل:

```text
جدیدترین
```

## نکته

لیست‌های فروش/خرید/مالی قبلاً بر اساس تاریخ نزولی یا آخرین ثبت مرتب هستند؛ این تغییر مخصوص خواسته‌ی کد مشتری/کالا بود.

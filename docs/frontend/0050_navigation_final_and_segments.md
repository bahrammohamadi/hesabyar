# 0050 — Navigation final and customer segments

## بخش ۱ — Sidebar نهایی

Sidebar به حداکثر دو سطح محدود شد: گروه اصلی → آیتم مستقیم.

ساختار نهایی:

```text
داشبورد
فروش: فاکتورهای فروش/POS، سفارش فروش، مرجوعی فروش
خرید: فاکتورهای خرید، مرجوعی خرید
اشخاص: همه اشخاص، مشتریان، تأمین‌کنندگان، بدهکاران/بستانکاران
کالا و انبار: کالاها، گردش انبار، کاردکس کالا، موجودی به تاریخ، ورود کالا، خروج کالا، تعدیل موجودی، ضایعات
مالی: تراکنش‌ها، دریافت، پرداخت، هزینه، درآمد، انتقال وجه، چک‌ها
باشگاه مشتریان: نمای کلی، سگمنت‌ها، امتیاز و کیف‌پول، کمپین‌ها
گزارش‌ها: نمای کلی گزارش‌ها، عملکرد فروشندگان، سود کالا/فاکتور، مشتریان سودآور، فعالیت کاربران
تنظیمات: داشبورد تنظیمات، کاربران و دسترسی‌ها، مالی و حساب‌ها، کاتالوگ، لیست قیمت‌ها
```

## یکپارچه‌سازی گزارش‌ها

در Sidebar حذف شدند ولی routeها باقی ماندند:

```text
/reports/sales
/reports/products
/reports/financial
/reports/contacts
/reports/profit
```

دلیل: بخش زیادی از محتوای آن‌ها در `/reports/overview-v2` پوشش داده می‌شود.

نگه داشته شدند:

```text
/reports/sellers — عملکرد تفصیلی فروشنده
/reports/profitability — سود کالا/فاکتور تفصیلی
/reports/customer-profitability — مشتریان سودآور
/activity — فعالیت کاربران
```

## Bottom-nav موبایل

پنج آیتم نهایی:

```text
داشبورد
فروش
اشخاص
کالا و انبار
بیشتر
```

«بیشتر» Sidebar کامل را باز می‌کند.

## بخش ۲ — Settings نهایی

صفحه `/settings` به داشبورد ۵ کارت بزرگ تبدیل شد:

```text
عمومی → /settings/catalog
کاربران و دسترسی‌ها → /settings/users
مالی → /settings/accounts
کاتالوگ → /settings/catalog
پیشرفته → /activity
```

صفحات زیرین حذف یا تغییر منطقی نشدند و فقط نقطه ورود ساده‌تر شد.

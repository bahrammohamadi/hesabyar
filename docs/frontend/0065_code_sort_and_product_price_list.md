# 0065 — مرتب‌سازی پیش‌فرض بر اساس کد و نمایش قیمت فروش کالا

## لیست اشخاص

فایل:

```text
app/(app)/contacts/page.tsx
```

مرتب‌سازی پیش‌فرض از «جدیدترین بر اساس تاریخ ثبت» به «جدیدترین بر اساس کد» تغییر کرد:

```text
code_desc
```

گزینه‌های مرتب‌سازی اکنون:

```text
جدیدترین بر اساس کد
قدیمی‌ترین بر اساس کد
جدیدترین بر اساس تاریخ ثبت
نام A-Z
نام Z-A
مانده بیشتر
مانده کمتر
```

## لیست کالاها

فایل:

```text
app/(app)/products/page.tsx
```

مرتب‌سازی پیش‌فرض از `newest` به `code_desc` تغییر کرد.

در کارت هر کالا، قیمت فروش به‌صورت badge واضح نمایش داده می‌شود:

```text
قیمت فروش: ...
```

قیمت نمایش‌داده‌شده از `base_sale_price` گرفته می‌شود و اگر خالی باشد از اولین واریانت دارای `sale_price` استفاده می‌شود.

# 0059 — Help tips and remaining UX completion

## راهنمای بخش‌ها

کامپوننت جدید `HelpTip` اضافه شد و به صورت خودکار در این الگوها نمایش داده می‌شود:

- `PageHeader` در صورت داشتن subtitle
- `Section` در صورت داشتن description
- `Field` در صورت داشتن hint

این یعنی بخش بزرگی از صفحات بدون تغییر دستی در همه فایل‌ها، علامت سؤال راهنما کنار عنوان/فیلد می‌گیرند.

## DatePicker

امکان تایپ مستقیم تاریخ شمسی مثل `۱۴۰۲/۰۱/۰۱` به DatePicker اضافه شد و با همان state انتخاب تقویمی یکسان کار می‌کند.

## فرم خرید

در فرم خرید، درصد سود علاوه بر نمایش، قابل ویرایش شد و با تغییر درصد، قیمت فروش از روی قیمت خرید محاسبه می‌شود.

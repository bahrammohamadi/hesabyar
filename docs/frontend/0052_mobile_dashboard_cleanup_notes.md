# 0052 — Mobile dashboard navigation cleanup

## گام صفر — عناصر بررسی‌شده

### 1) آیکون ☰ در Header

فایل:

```text
components/shared/header.tsx
```

رفتار قبلی:

```tsx
onClick={onMenuClick}
```

همان Sidebar موبایل را باز می‌کرد. بعد از اضافه‌شدن آیتم «بیشتر» در bottom-nav، این دکمه روی موبایل تکراری بود.

اقدام: حذف شد. راه دسترسی موبایل به Sidebar فقط `بیشتر` در bottom-nav است.

### 2) دکمه شناور + / ⚡

فایل:

```text
components/shared/mobile-fab.tsx
components/shared/app-shell.tsx
```

رفتار قبلی:

- فروش جدید
- خرید جدید
- مشتری جدید
- کالای جدید

همه این‌ها یا در bottom-nav یا در گرید «عملیات سریع» داشبورد وجود دارند.

اقدام: `MobileFab` از `AppShell` حذف شد. خود فایل حذف نشد تا اگر بعداً لازم شد، routeها/کدها از بین نروند؛ فقط دیگر در UI موبایل render نمی‌شود.

### 3) آیکون کیف‌پول/اعتبار

آیکون کیف‌پول مستقلی به‌عنوان FAB عمومی پیدا نشد. موارد یافت‌شده مربوط به کارت/ماژول Loyalty یا فیلد پرداخت از اعتبار در فاکتور هستند و حذف نشدند.

### 4) Badge میانبر F2

فایل‌ها:

```text
app/(app)/dashboard/page.tsx
app/(app)/dashboard/components/DashboardQuickActions.tsx
```

`F2` فقط میانبر دسکتاپ است. روی موبایل مخفی شد:

```text
hidden lg:inline / hidden lg:inline-flex
```

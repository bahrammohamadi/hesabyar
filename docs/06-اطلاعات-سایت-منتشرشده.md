## 🔴 کارهای امنیتی مهم (همین حالا انجام دهید!)

چون توکن‌ها و کلیدها در چت رد و بدل شدند، برای امنیت کسب‌وکارتان:

1. **توکن GitHub** را باطل کنید: github.com/settings/tokens → روی توکن `hesabyar-deploy` → Delete
2. **توکن Vercel** را باطل کنید: vercel.com/account/tokens → Delete
3. **کلیدهای محرمانه Supabase** را بچرخانید: Supabase → Settings → API → Rotate `service_role` و `secret`
   - ⚠️ توجه: کلید **anon** را عوض نکنید (سایت به آن وصل است). اگر anon را هم چرخاندید، باید متغیر محیطی Vercel را به‌روز کنیم.

> این کارها ضروری‌اند چون کلیدهای محرمانه را در چت فرستادید.

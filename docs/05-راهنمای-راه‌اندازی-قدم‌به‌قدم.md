# 🚀 راهنمای راه‌اندازی قدم‌به‌قدم (مخصوص افراد غیرفنی)

> اپلیکیشن کامل ساخته شده و تست بیلد آن موفق بوده است. حالا فقط باید آن را «روشن» کنیم.
> هر مرحله را دقیقاً مثل دستور انجام بده. هر جا گیر کردی، یک اسکرین‌شات بفرست.

ترتیب کار: **۱) Supabase → ۲) اجرای دیتابیس → ۳) GitHub → ۴) Vercel → ۵) ورود اطلاعات شاتوت**

---

## مرحله ۱ — ساخت پروژه Supabase (بک‌اند و دیتابیس)

1. به https://supabase.com برو و **Start your project** را بزن.
2. با **GitHub** وارد شو (دکمه Continue with GitHub).
3. **New Project** را بزن:
   - **Name:** `hesabyar`
   - **Database Password:** یک رمز قوی بساز و **در جای امن یادداشت کن**.
   - **Region:** `Central EU (Frankfurt)` را انتخاب کن.
4. حدود ۲ دقیقه صبر کن تا پروژه آماده شود.

### گرفتن کلیدها (مهم — بعداً لازم می‌شود)
- از منوی چپ: **Project Settings (چرخ‌دنده) → API**
- این دو مقدار را کپی و یادداشت کن:
  - **Project URL** (شبیه `https://xxxx.supabase.co`)
  - **anon public** key (یک رشته طولانی)

---

## مرحله ۲ — ساختن دیتابیس (اجرای فایل‌های SQL)

1. در Supabase از منوی چپ روی **SQL Editor** بزن.
2. **New query** را بزن.
3. فایل `supabase/migrations/0001_initial_schema.sql` را باز کن، **کل محتوا** را کپی کن، در ادیتور پیست کن و **Run** را بزن.
   - باید پیام موفقیت (Success) ببینی.
4. دوباره **New query** بزن.
5. فایل `supabase/migrations/0002_functions.sql` را کپی/پیست کن و **Run** بزن.

✅ حالا دیتابیس کامل ساخته شده: همه جدول‌ها، امنیت RLS و توابع فروش/خرید.

### تنظیم احراز هویت (برای سادگی اولیه)
- منوی چپ: **Authentication → Providers → Email**
- گزینه **Confirm email** را **خاموش** کن (تا برای شروع نیازی به تأیید ایمیل نباشد).
  > بعداً برای امنیت بیشتر می‌توان روشن کرد.

---

## مرحله ۳ — آپلود کد روی GitHub

> دو راه دارد. راه آسان‌تر (بدون نصب چیزی) را توضیح می‌دهم.

### راه آسان: آپلود مستقیم در سایت GitHub
1. به https://github.com برو و وارد شو.
2. روی **+** بالا سمت راست → **New repository**.
   - **Repository name:** `hesabyar`
   - **Private** را انتخاب کن.
   - **Create repository** را بزن.
3. من کل فایل‌های اپ را در پوشه `financeapp` آماده کرده‌ام. این پوشه را از فضای کاری دانلود کن.
4. در صفحه‌ی ریپازیتوری، روی **uploading an existing file** بزن و همه‌ی فایل‌های داخل `financeapp` را بکش و رها کن (drag & drop).
   - ⚠️ فایل `.env.local` را آپلود نکن (وجود ندارد و نباید باشد).
5. **Commit changes** را بزن.

---

## مرحله ۴ — انتشار روی Vercel

1. به https://vercel.com برو و با **GitHub** وارد شو.
2. **Add New → Project** را بزن.
3. ریپازیتوری `hesabyar` را پیدا کن و **Import** بزن.
4. در بخش **Environment Variables** این دو متغیر را اضافه کن (از مرحله ۱):
   - `NEXT_PUBLIC_SUPABASE_URL` = همان Project URL
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY` = همان anon public key
5. **Deploy** را بزن و چند دقیقه صبر کن.
6. وقتی تمام شد، یک آدرس مثل `https://hesabyar-xxx.vercel.app` می‌گیری. 🎉

### اولین ورود
1. آدرس Vercel را باز کن.
2. به صفحه **ثبت‌نام** برو (`/register`).
3. **نام کسب‌وکار، ایمیل و رمز** را وارد کن و ثبت‌نام کن.
   - با این کار، سازمان + شعبه اصلی + صندوق + بانک + دسته‌های هزینه خودکار ساخته می‌شوند.
4. وارد داشبورد می‌شوی. ✅

---

## مرحله ۵ — ورود اطلاعات شاتوت (کالاها و مشتری‌ها)

> این کار را **بعد از اولین ثبت‌نام** انجام بده (چون به سازمان تو نیاز دارد).

1. در Supabase → **SQL Editor → New query**.
2. فایل `data/import-products.sql` را کپی/پیست کن و **Run** بزن.
   - ۳۶۷ کالا با موجودی اول دوره وارد می‌شوند.
3. دوباره New query → فایل `data/import-customers.sql` را Run کن.
   - ۵۴۰ مشتری وارد می‌شوند (همراه تاریخ تولد برای CRM آینده).
4. در اپ، به بخش **کالا و انبار** و **اشخاص** برو — باید همه‌چیز را ببینی. 🎉

حالا یک نرم‌افزار مالی واقعی، آنلاین، فارسی و قابل‌نصب روی موبایل داری.

## نکات و عیب‌یابی
- اگر بعد از ورود، داشبورد خالی بود: طبیعی است، هنوز فروش ثبت نشده.
- اگر «دسترسی غیرمجاز» دیدی: مطمئن شو با همان حسابی وارد شده‌ای که سازمان را ساخته.
- هر تغییری در کد روی GitHub بدهی، Vercel خودکار دوباره منتشر می‌کند.
- برای افزودن رنگ/سایز به کالاهای واردشده: در بخش **کالا و انبار**، روی هر کالا بزن و تنوع اضافه کن.

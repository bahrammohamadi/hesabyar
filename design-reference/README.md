# design-reference

این پوشه **مرجع بصری** برای بازطراحی UI پروژه حساب‌یار است.

## ⚠️ قانون اصلی

> **هیچ فایلی از این پوشه نباید مستقیماً در کد اپلیکیشن `import` شود.**

این پوشه فقط حاوی مستندات طراحی، اسکرین‌شات‌ها و مراجع بصری است. محتوای آن:

- در build نهایی شرکت نمی‌کند
- توسط هیچ کامپوننت، صفحه یا ماژولی import نمی‌شود
- صرفاً برای مشاهده توسط توسعه‌دهنده/طراح در حین بازطراحی است

## محتوا

| فایل | توضیح |
|---|---|
| `DESIGN.md` | سند اصلی جهت‌گیری طراحی (به‌زودی اضافه می‌شود) |
| `screenshots/` | اسکرین‌شات‌های مرجع (به‌زودی اضافه می‌شود) |

## چرا این پوشه در ریپو است؟

نگه‌داشتن مرجع بصری کنار کد باعث می‌شود تصمیمات طراحی همراه با تاریخچه‌ی گیت حفظ شوند و در بازبینی‌های بعدی قابل ردیابی باشند.

اگر حجم اسکرین‌شات‌ها زیاد شد، بهتر است به storage خارجی منتقل شده و فقط لینک آن‌ها اینجا بماند.

## وضعیت

بازطراحی UI در برنچ `design/stitch-refresh` دنبال می‌شود.
برای درک وضعیت فعلی سیستم کامپوننت‌ها، فایل `MIGRATION_NOTES.md` در ریشه پروژه را ببینید.

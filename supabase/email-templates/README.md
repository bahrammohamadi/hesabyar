# قالب‌های ایمیل فارسی ترازو

## چرا این‌ها هنوز فعال نیستند

تلاش برای اعمال خودکار این قالب‌ها با این پاسخ رد شد:

```
HTTP 400
Email template modification is not available for free tier projects
using the default email provider. Please upgrade your plan or
configure a custom SMTP provider.
```

یعنی سوپابیس در پلن رایگان و با فرستنده‌ی پیش‌فرض، اجازه‌ی تغییر قالب
نمی‌دهد. تا وقتی SMTP اختصاصی تنظیم نشود، کاربر همان ایمیل انگلیسی
پیش‌فرض سوپابیس را می‌گیرد.

## چه چیزی اعمال شد

`site_url` از `http://localhost:3000` به `https://tarazooapp.vercel.app`
تغییر کرد.

این یک باگ فعال بود، نه بهبود: لینک تأیید ایمیل به localhost اشاره
می‌کرد و روی دستگاه کاربر واقعی **هرگز باز نمی‌شد**. هر کسی که با ایمیل
واقعی ثبت‌نام می‌کرد، عملاً نمی‌توانست حسابش را تأیید کند.

## فعال‌سازی قالب‌ها (وقتی SMTP آماده شد)

### گام ۱ — یک سرویس SMTP بگیرید

گزینه‌های رایگان یا ارزان:

| سرویس | حجم رایگان | نکته |
|---|---|---|
| Resend | ۳٬۰۰۰ ایمیل در ماه | راه‌اندازی ساده، نیازمند تأیید دامنه |
| Brevo | ۳۰۰ در روز | بدون نیاز به کارت |
| Mailgun | آزمایشی محدود | نیاز به کارت |
| SMTP ایرانی | متغیر | برای ارسال به کاربر ایرانی تحویل‌پذیری بهتری دارد |

⚠️ برای همه‌ی این‌ها به دامنه‌ی `tarazoo.ir` (یا هر دامنه‌ی دلخواه) و
دسترسی به رکوردهای DNS نیاز دارید تا SPF/DKIM تنظیم شود. بدون آن
ایمیل‌ها به پوشه‌ی اسپم می‌روند.

### گام ۲ — SMTP را در سوپابیس ثبت کنید

`Dashboard → Project Settings → Authentication → SMTP Settings`

نام فرستنده را `ترازو` و ایمیل فرستنده را مثلاً `no-reply@tarazoo.ir`
بگذارید.

### گام ۳ — قالب‌ها را اعمال کنید

پس از فعال‌شدن SMTP، همان اسکریپت دوباره کار می‌کند:

```bash
python3 /tmp/mail_tpl.py
```

یا دستی: `Dashboard → Authentication → Email Templates` و محتوای
هر فایل این پوشه را در قالب متناظرش بچسبانید. موضوع‌ها در
`subjects.json` هستند.

## فایل‌ها

| فایل | کاربرد |
|---|---|
| `confirmation.html` | تأیید ایمیل هنگام ثبت‌نام — به ۱۴ روز تست اشاره می‌کند |
| `recovery.html` | بازیابی رمز عبور |
| `magic_link.html` | ورود بدون رمز |
| `invite.html` | دعوت همکار به کسب‌وکار |
| `email_change.html` | تأیید ایمیل جدید |

همه RTL، با سربرگ سبز برند، فونت وزیرمتن و لینک پشتیبان متنی (برای
کلاینت‌هایی که دکمه را رندر نمی‌کنند).

## گزینه‌ی جایگزین: خاموش‌کردن تأیید ایمیل

اگر می‌خواهید کاربر اصلاً درگیر ایمیل نشود:

`Dashboard → Authentication → Providers → Email → Confirm email = off`

آن‌وقت ثبت‌نام بلافاصله نشست می‌سازد و کاربر مستقیم به `/onboarding`
می‌رود. مسیر کوتاه‌تر می‌شود ولی ایمیل‌های جعلی هم پذیرفته می‌شوند.
**این تصمیم با شماست؛ عمداً تغییرش ندادم.**
